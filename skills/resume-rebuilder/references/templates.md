# 模板（templates）

## 会话内备忘录模板

在阶段 0 建立，路径按运行环境动态选择（见 SKILL.md 原则：优先用会话临时目录，否则系统临时目录，不要写死 `/tmp`）。每锁定一块就追加/更新。后续只信此文件。

```markdown
# 简历草稿 — <用户标识> — <日期>

## 基本信息
- 当前背景：<如 前端 3 年>
- 目标岗位：<岗位名>
- JD 核心要求：<3-5 条关键词/能力>

## 规划
- 项目清单：A / B / C
- 权重分配：<如 目标方向 70% / 旧背景 30%>

## 锁定内容

### 项目 A — <一句话>
状态：✅已锁定
口语原话：<用户原话>
简历写法：
- <动词+内容+量化>
- <动词+内容+量化>
JD 匹配：<对应 JD 哪条 ✅>

### 项目 B — <一句话>
状态：🔄进行中
...

## JD 差距分析
- 匹配 ✅：...
- 缺口 ⚠️：...
```

## 最终简历产出模板（Markdown）

```markdown
# <姓名> — <目标岗位>

## 个人总结
<一句话背景 + 专长/转型路径，含关键量化或技术标签>

## 工作经历
### <公司> — <职位> — <时间>
- 职责：<负责什么>
- 成果：
  - <动词+内容+量化>
  - <动词+内容+量化>

## 项目经历
### <项目名> — <角色> — <时间>
- <动词+内容+量化>
- <动词+内容+量化>（含技术栈标签）

## 技能
- 精通：<JD 强相关的>
- 熟练：<相关但次要的>
- 了解：<旧背景/可迁移的>
```

## "口语原话 → 简历语言"对照示例

> 口语原话：我搞了个小助手，能查数据库，然后回答问题，还挺好用的。
>
> 简历语言：主导搭建基于 LLM 的问答助手，接入内部数据库实现自然语言查询，将非技术同学的数据获取耗时从约 30 分钟缩短到分钟级。
